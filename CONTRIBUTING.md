# Contributing

## Before You Code

- [ ] Read `AGENTS.md`.
- [ ] Check `PLAN.md` for the active milestone.
- [ ] Check `DECISIONS.md` for architecture constraints.
- [ ] Check current official docs for the area you are changing.
- [ ] Update `LEARNINGS.md` if new verified source material changes implementation.

## Development

- [ ] Run `pnpm install`.
- [ ] Run `pnpm dev` for local services.
- [ ] Keep changes focused and permanent.
- [ ] Add or update tests for behavioral changes.
- [ ] Do not broaden extension permissions without a security decision.

## Pull Requests

- [ ] Use Conventional Commits for branch commits.
- [ ] Explain user impact and security/privacy impact.
- [ ] Include test results.
- [ ] Confirm no Netflix sensitive data is collected.
- [ ] Confirm docs are updated when behavior, architecture, or workflows change.

## Review Standard

- [ ] Correctness before style.
- [ ] Security boundaries before convenience.
- [ ] Minimal public API before broad abstractions.
- [ ] Delete unused code through cleanup PRs with tests.
